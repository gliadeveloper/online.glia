## 0. 한 줄 요약

GLIA 회복 웰니스의 진입 화면. 오늘의 리듬을 확인하고 학습·코칭·커뮤니티로 이어진다.

---

## 2. 사용자 목표

- 오늘의 데일리 체크인을 작성하거나 오늘 기록을 다시 본다.
- 수강·코칭 여정을 이어 가거나, 없으면 프로그램을 탐색한다.
- 미열람 소식(라이브·코멘트·회차)이 있으면 대상 화면으로 이동한다.

---

## 3. 화면 구조

1. **Hero** — 대기 그라데이션, 인사, 철학 카피(뇌 · 몸 · 회복 · 균형), 체크인 카드
2. **지금 확인할 소식** — 미열람 알림. 0건이면 섹션 숨김
3. **이어가는 여정** — 수강 1 + 코칭 1. 로그인 전용. 없으면 탐색 안내
4. **균형의 네 축** — 학습 / 코칭 / 회복 / 커뮤니티
5. **프로그램 탐색** — 활성 상품 최대 3

---

## 4. 상태

| 상태 | 홈 |
|------|-----|
| 비로그인 | 히어로 + 체크인 CTA + 네 축 + 상품 탐색. 알림·여정 숨김 |
| 로그인 · 미보유 | 히어로 + 알림(있으면) + 여정 empty + 네 축 + 상품 탐색 |
| 로그인 · 보유 | 히어로 + 알림(있으면) + 이어하기 + 네 축 + 추천 탐색 |

체크인 CTA: 미완료 → 오늘 데일리 폼. 완료 → 오늘 리포트.
