# /coach/questions — 강의 질문

> **상태:** implemented  
> **마지막 갱신:** 2026-09-28

## 0. 한 줄 요약

강사가 본인 코스에 올라온 강의 질문 중 아직 답하지 않은 것을 보고, 답하고, 채택하고, 닫는다.

---

## 1. 라우팅 & Chrome

| 항목 | 내용 |
|------|------|
| **URL** | `/coach/questions` |
| **Tab/Stack** | Coach portal. 사이드 메뉴 **질문** |
| **Chrome** | 코치 셸. 미답변 수가 메뉴에 표시 |
| **진입** | 코치 메뉴, 홈 알림 「새 강의 질문」 |
| **정책 SSOT** | [policies.md](../../policies.md) §5.6 · §7 |
| **용어** | 미답변 = 닫히지 않았고, 강사 본인 답변이 없는 질문 |

---

## 2. 사용자 목표

- 답해야 할 질문을 한곳에서 처리
- 답변을 남기고, 맞는 답을 채택하거나 질문을 닫음

---

### Block: 질문 행

| | |
|-|-|
| **역할** | 질문 하나를 읽고 처리 |

| # | UI 요소 | 데이터·규칙 | v1 |

| 3 | 기존 답변 | 채택 답이 위. 업보트 순 | ✅ |
| 4 | 답변 입력 | 닫힌 질문은 숨김 | ✅ |
| 5 | 채택 | 답변 하나. 다시 누르면 해제 | ✅ |
| 6 | 닫기 | 새 답변 중단 | ✅ |

| 트리거 | 결과 | 대상 |
|--------|------|------|
| 답변 | 질문 작성자에게 알림 | `POST /api/learning/lessons/[lessonId]/questions/[questionId]/replies` |
| 채택 / 닫기 | 수강생 화면과 동일 API | accept · PATCH |
| 알림으로 진입 | 해당 질문을 펼침 | `?question=[questionId]` |
